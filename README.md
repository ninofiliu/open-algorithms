# Open Algorithms

Open Algorithms is a collection of visual art algorithms by [Nino Filiu](https://ninofiliu.com) that run in the browser to process user-provided media (pictures, videos, or webcam stream) in order to glitch them or create interesting visuals.

Everything is open sourced on [Github](https://github.com/ninofiliu/open-algorithms).

[Pexcil](https://nf-open-algorithms.netlify.app/pexcil): initially designed as an algorithm to realistically imitate the way I used my pencil to draw, was eventually deemed much more interesting when using unrealistic parameters.

[Diffractia](https://nf-open-algorithms.netlify.app/diffractia): a WebGL algorithm that progressively shifts the pixels of a source image using a diffraction image.

[MotionCam](https://nf-open-algorithms.netlify.app/motioncam): a WebGL algorithm that detects motion from a live camera feed by diffing consecutive frames.
